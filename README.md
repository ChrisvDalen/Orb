# Orb

A dependency-free HTML canvas animation that renders a rotating, multicoloured orb.

## Run locally

Serve the repository with any static HTTP server, for example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Validation

The project targets modern browsers and has no package-manager dependencies. GitHub Actions
checks the JavaScript syntax with Node.js 24 and verifies that the referenced static assets exist.
